## 1. 디자인 필러 [확정]

1. **감정 = 색**: 색은 감정의 각인이다. 색을 되찾는 것이 곧 감정과 기억을 되찾는 것이다.
2. **남매의 재발견**: 서로가 가족이라는 사실을 잊은 두 사람이 닮은 습관과 공명으로 서로를 다시 알아본다.
3. **상실 후의 따뜻함**: 잃어버린 것을 슬퍼하되, 결말의 정서는 따뜻함이다.

표현 수위 상한: **15세 이용가**. 청소년이용불가 요소는 넣지 않는다(비영리 공개 시 등급분류 면제 조건).

### 10-2. 계획서 엔딩 표의 빈틈 (폴백이 필요한 이유)

계획서 표만으로는 어떤 엔딩에도 도달하지 못하는 상태가 생긴다.

1. **균형인데 조건 미달**: `abs(protect - heal) <= 2`이지만 `bond < 4` 또는 `families_reunited < 3`이면 가족·치유·보호 어느 조건도 맞지 않는다. 예: protect 10, heal 10, bond 3.
2. **치유 미달의 폴백 대상이 없음**: 계획서는 "치유 조건 미달이면 보호/가족으로 폴백"이라고 했지만, `heal - protect >= 3`인 상태는 보호(`protect - heal >= 3`)와 가족(`abs <= 2`) 조건을 둘 다 만족할 수 없다.

**[제안]** 위 두 경우 모두 **보호 엔딩**으로 보낸다(표의 6번). 이유: 조건이 가장 단순하고, "아직 함께하지 못함"이라는 기본 결말로 읽힌다. 다만 보호 엔딩의 실제 내용이 이 역할에 맞는지는 **TODO-확인**. 다른 안: 별도의 "미완(노멀)" 엔딩 추가 — 범위가 늘어나므로 권장하지 않는다.

분기 시뮬레이터(WP-07, `tools/branch_sim.py`)는 이 표를 그대로 구현하고, 모든 입력 조합이 정확히 하나의 엔딩에 도달하는지 검사한다.
