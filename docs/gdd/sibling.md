## 3. 태그 전환

| 항목 | 규칙 |
|---|---|
| 해금 | `flag.ch1.met_in_square = true`(이벤트 `ev_ch1_square_meeting`) |
| 입력 | `tag_switch` (키보드 Tab, [controls_accessibility.md](controls_accessibility.md)) |
| 쿨다운 | **0.5초** |
| 카메라 | 새 활성 캐릭터로 **0.3초** 이동. 리듀스 모션이면 즉시 컷 |
| 쓸 수 없을 때 | 대사, 퍼즐(2인 변형 제외), 컷신·컷인, 메뉴, **단독 구간**(장면 설정으로 한 사람만 조작하는 구간) |
| 피드백 | 전환음 + 새 활성 캐릭터 발밑에 감정 기호 0.5초 |
| 저장 | `location.active_character` |

### 3-1. 비활성 캐릭터

| 모드 | 언제 | 동작 |
|---|---|---|
| 따라가기 | 기본 | 활성 캐릭터의 지나간 길(빵부스러기 기록)을 **24 px** 뒤에서 따라간다. 내비게이션 메시 없이 구현 |
| 순간 이동 | 따라가기 중 거리 > **160 px** | 화면 밖에서 활성 캐릭터 뒤로 옮긴다 |
| 머물기 | 동시 퍼즐 구역 안, 또는 무언가를 붙잡고 있을 때 | 그 자리에 선다. 대기 애니메이션 |

## 4. 동시 조작 퍼즐

입력은 기존 8개 액션만 쓴다. 한 사람을 "세워 두고" `tag_switch`로 다른 사람을 움직이는 방식이다(계획서 ②-3 "한 명이 붙잡고 다른 한 명이 이동"). **실패 상태는 없다.**

### 4-1. 유형

| 유형 | 규칙 | 필요 bond |
|---|---|---|
| 붙잡기-이동 | A가 붙잡는 장치(문·밧줄·셔터)에서 `interact` → 계속 붙잡고 있음 → `tag_switch` → B가 통과 → B가 반대편 장치를 고정하면 A가 풀려난다 | 1 |
| 두 발판 | 발판 두 개가 동시에 눌려야 열린다. 한 명을 발판에 세워 두고 전환 | 1 |
| 기억의 다리 | A가 공명대 위에서 `echo_sense` 중 `interact` → 감지가 **고정**된다 → 반경 안의 회색 길이 실체가 된다 → `tag_switch` → B가 건넌다. A로 돌아오거나 B가 다 건너면 풀린다 | 2 |
| 엇갈린 시선 | 각자만 보는 단서(상대 전용 잔향의 점선 윤곽, [echo.md](echo.md) §2-4)를 조합한다. 예: 하늘이 본 기호 순서를 별이 장치에 입력 | 2 |

### 4-2. 배치 (8개)

| # | 장면 | 유형 | 비고 |
|---|---|---|---|
| 1 | `ch1_square_02` | 붙잡기-이동 | 튜토리얼. 태그 전환을 처음 배운다 |
| 2 | `ch2_park_02` | 두 발판 | |
| 3 | `ch2_alley` | 붙잡기-이동 | 보호 컷인 #1과 같은 장면 |
| 4 | `ch3_studio_02` | 기억의 다리 | |
| 5 | `ch3_room_02` | 엇갈린 시선 | |
| 6 | `ch3_hill` | 두 발판 + 기억의 다리 | |
| 7 | `ch4_conflict_04` | 엇갈린 시선 | |
| 8 | `ch4_storm_before` | 기억의 다리 | 폭풍 직전, 가장 긴 퍼즐 |

- 각 퍼즐 목표 시간 **1~3분**. 막히면 비활성 캐릭터가 힌트 대사를 한다(30초마다 1줄, 최대 3줄).
- 필수 진행 퍼즐에는 그 챕터에서 **이미 보장된** bond만 요구한다(조건부 bond 4로 막히지 않게).

## 5. 상호작용 4종 + bond 해금표

### 5-1. 상호작용 규칙 (canon §7을 규칙으로)

| 상호작용 | 게임 규칙 | 자세히 |
|---|---|---|
| 보호 본능 | 위험 이벤트에서 자동 컷인(`[#cutin=protect]`) → 성향 선택지 | §7 |
| 공감 연결 | 활성 캐릭터가 감지하면 상대 전용 잔향이 점선 윤곽으로 보인다 | [echo.md](echo.md) §2-4 |
| 기억 공유 | 공명 잔향(`both`)을 수집하면 두 시점을 분할 화면으로 겹친다 | §8 |
| 협력 강화 | bond 단계별로 감지 반경·동시 퍼즐·공명 잔향이 열린다 | 아래 표 |

### 5-2. bond 0~4 해금표

| bond | 언제 오르나 | 감지 반경 | 공감 연결 | 동시 퍼즐 | 공명 잔향 | 그 밖 |
|---|---|---|---|---|---|---|
| 0 | 시작 ~ 광장 전 | 80 px | 연출만(잔상 2회) | — | — | 교대 파트 |
| 1 | `ch1_square` 첫 만남 (필수) | 80 px, 공명 시 ×1.25 | 점선 윤곽, 비활성 `!` | 붙잡기-이동, 두 발판 | `bond_min 1` 잔향 | 태그 전환 |
| 2 | `ch2_attic` 다락방 (필수) | 88 px | 같음 | + 기억의 다리, 엇갈린 시선 | `bond_min 2` 잔향 | 공명 퍼즐 2인 변형(CM-C) |
| 3 | `ch3_artwork` 협력 작품 (필수) | 96 px | 같음 | 같음 | `bond_min 3` 잔향 | 보호 컷인의 보호자 = 활성 캐릭터(그 전에는 항상 하늘, §7) |
| 4 | `ch4_storm_after` **조건부** / `ch5_echo` 만회 | 104 px | 함께 감지 시 실선 윤곽 | 같음 | — | 가족·기적 엔딩 조건, 엔딩 대사 변형 |

- bond는 **스토리 이벤트로만** 오른다(canon §9). 대사에서 `$> GameState.raise_bond(n)`.
- bond 4 조건과 만회 규칙은 [endings.md](endings.md) §4. 요약: 공명 잔향을 **7개 이상** 모았을 때.
- bond 4의 혜택은 보기·편의뿐이다. 진행 필수 콘텐츠를 bond 4로 막지 않는다.

## 6. 공명 (canon W-RES)

"두 사람이 같은 감정을 동시에 느끼면" 생기는 효과를 아래로 한정한다.

| 공명 | 조건 | 효과 |
|---|---|---|
| 감지 공명 | 두 사람이 40 px 안, bond ≥ 1 | 감지 반경 ×1.25 |
| 공명 잔향 | `both` 잔향 수집 | 기억 공유 분할 화면 + 정원 같은 감정 칸 +1 |
| 정원 공명 | `ev_ch3_garden_resonance` | 정원 모든 칸 +1 |
| 대사 공명 `[#sync]` | 대사 연출 | 연출만(화음 효과음, 두 초상이 같이 흔들림). 수치 효과 없음 |

## 7. 보호 본능 컷인

| 항목 | 사양 |
|---|---|
| 태그 | 대사 줄 앞 `[#cutin=protect]` |
| 길이 | **1.2초**. 입력 잠금. 본 적 있는 컷인은 `interact`로 건너뛸 수 있다 |
| 보호자 | **그 순간의 활성 캐릭터.** 단독 구간이면 그 장면의 조작 캐릭터 |
| 그림 | 2장만 그려 재사용: 하늘이 감싸는 포즈, 별이 감싸는 포즈 |
| 이어지는 것 | 성향 선택지 1개. 지키는 응답 = `add_protect`, 다독이는 응답 = `add_heal`. 컷인은 선택을 강요하지 않는다 |
| 리듀스 모션 | 줌·흔들림 없이 정지 그림 페이드 |
| 위험의 내용 | 장면 작가가 정한다. 15세 이용가 안에서(부상 묘사 없음) |

| # | 장면 | 연결된 선택지 ([endings.md](endings.md) §3) |
|---|---|---|
| 1 | `ch2_alley` | C2-6 |
| 2 | `ch3_studio_02` | C3-3 (핵심 +2) |
| 3 | `ch3_hill` | C3-6 |
| 4 | `ch4_conflict_02` | C4-2 |
| 5 | `ch4_storm_before` | C4-5 (핵심 +2) |
| 6 | `ch5_square` | C5-4 (핵심 +2) |

- 보호자를 활성 캐릭터로 둔 이유: 플레이어가 직접 고른 사람이 지키는 느낌을 주고, 한 방향(오빠가 동생을 지키는 구도)으로만 고정되지 않게 한다. bond 3 전에는 활성 캐릭터와 관계없이 하늘이 보호자다(관계 회복 전 연출). **[제안]**

## 8. 기억 공유 (분할 화면)

| 항목 | 사양 |
|---|---|
| 언제 | 공명 잔향(`both`) 9개를 수집할 때 |
| 화면 | 세로로 반 나눔: 왼쪽 = 하늘 시점, 오른쪽 = 별 시점(각 240×270) |
| 그림 | 기억 컷 **한 장**(480×270 스케치)을 반씩 보여 주고, 각 시점의 감정 색만 강조. 추가 그림을 그리지 않는다 |
| 대사 | 시점마다 1~2줄(화면 아래 각자의 말풍선) |
| 길이 | **6~10초**, 끝나면 가운데로 합쳐진다 |
| 리듀스 모션 | 닦아내기 대신 교차 페이드 |
| bond 조건 | 잔향의 `bond_min`을 따른다([echo.md](echo.md) §5-3) |
