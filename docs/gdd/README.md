## 핵심 루프 (한 화면 요약)

```mermaid
flowchart LR
    A[탐색<br/>무채색 장면] --> B[잔향 감지<br/>echo_sense 홀드]
    B --> C[공명 퍼즐<br/>30~60초, 실패 없음]
    C --> D[색 조각 + 기억 컷<br/>그 자리 색 복원]
    D --> E[정원<br/>심기 · 성장 · 조합]
    E --> F[관계 복원<br/>bond · 공명 · 선택]
    F --> A
    F -.챕터 2~5 선택 누적.-> G[엔딩 5종]
```

| 단계 | 플레이어가 하는 것 | 돌려받는 것 | 문서 |
|---|---|---|---|
| 1 탐색 | 무채색 장면을 걷고, 사람과 이야기하고, 물건을 조사한다. 광장 이후에는 하늘·별을 바꿔 가며 | 이야기, 성향 선택지(챕터 2~5에 24개) | [progression.md](progression.md) |
| 2 잔향 감지 | `echo_sense`를 누르고 있으면 80 px 안 잔향이 감정 색 윤곽 + 기호로 맥동한다 | 잔향 위치. 상대 전용 잔향은 점선(공감 연결) → 태그 전환 | [echo.md](echo.md) §2 |
| 3 공명 퍼즐 | 감정 색 맞추기 / 기억 순서 맞추기. 기호만으로도 풀린다 | 목표 시간을 넘기면 힌트. 실패 없음 | [echo.md](echo.md) §3 |
| 4 색 조각 | — | 색 조각(씨앗), 기억 컷, 그 자리의 색 복원, 챕터 전역 채도 상승 | [echo.md](echo.md) §4 |
| 5 정원 | 각자 자기 줄에 씨앗을 심는다. 정원 방문을 마칠 때마다 +1 성장 | 조합 꽃, 가족의 꽃(챕터 4 트리거), 무지개 꽃(기적), 마음 화단(파랑:초록 = 성향) | [garden.md](garden.md) |
| 6 관계 복원 | 공명 잔향에서 기억 공유, 동시 조작 퍼즐, 보호 컷인 뒤 선택 | bond 1→4(감지 반경·동시 퍼즐 해금), 가족 재결합, 엔딩 조건 | [sibling.md](sibling.md), [endings.md](endings.md) |

**한 챕터의 리듬**: 도입 → 장소 2~3곳(잔향·사이드 가족·동시 퍼즐) → 정원(중간) → 핵심 장소(미션·bond 상승) → 정원(마무리) → 밤 장면(미수집 숨김 안내).

## 주요 수치 한눈에 보기 (모두 [제안])

| 항목 | 값 |
|---|---|
| 잔향 | 30개 = 필수 18 + 숨김 12. 챕터별 2 / 6 / 7 / 7 / 5 / 3. 감지 주체 하늘 11 · 별 10 · 공명 9 |
| 감지 | 반경 80 px(bond 2부터 +8씩, 공명 ×1.25), 0.6초 확장, 숨김은 반경 60% 안 |
| 퍼즐 | 목표 30~60초, 난이도 1~5, 힌트 2번 뒤 건너뛰기 가능 |
| 정원 | 10칸(2×5), 성장 틱 7회, 가족의 꽃 = 5색 각 성장 2 이상 |
| bond | 1·2·3은 챕터 1·2·3 필수 이벤트, 4는 공명 잔향 7개 이상(챕터 4, 챕터 5에서 만회) |
| 선택지 | 24지점 = 일반 18(+1, 10곳은 중립 있음) + 핵심 6(+2, 중립 없음). 축별 최대 30 |
| 장면·시간 | 55장면 + 엔딩 5, 1회차 6.0~8.9시간(중앙 약 7.5시간), 데모는 `ch1_square_02` 직후에서 끊기 |
| 전역 채도 | 0.00 → 0.10 → 0.25 → 0.40 → 0.50 → (폭풍 0.00) → 0.70 → 0.85 → 엔딩 0.90~1.00 |
| 오디오 | BGM 20곡, SFX 110개, −16 LUFS, 44.1 kHz OGG |
