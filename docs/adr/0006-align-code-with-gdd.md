# ADR-0006: 코드를 GDD(WP-06) 수치에 맞춤

- 상태: 승인 (개발자 위임, 2026-11-26)
- 날짜: 2026-11-26

GDD(`docs/gdd/`)가 정한 [제안] 수치에 맞춰 W1·W2 구현을 고쳤다. 수치를 다시 바꿀 때는 GDD를 먼저 고치고 코드·테스트를 따라 바꾼다.

| 항목 | 이전 | 지금 (GDD) |
|---|---|---|
| 입력 | 감지 Space, 상호작용 E/Z, 일시정지 Esc | 감지 Shift/X/RT/RB(홀드), 상호작용 E/Space/Z/A, 전환 Tab/C/Y, 일시정지 Esc/P/Start |
| 걷기 | 72 px/s | 80 px/s, 감지 중 ×0.6 |
| 감지 반경 | 96 px, 0.3초 지연 | 80 px + bond(2:+8, 3:+16, 4:+24), 두 사람 40px 안 + bond≥1 이면 ×1.25, 0.6초 ease-out, 지연 없음 |
| 숨김 잔향 | 일반과 같음 | 현재 반경의 60% 안 |
| `both` | 둘 중 누구나 | 두 사람이 64px 안에 함께 있을 때만 (공명 잔향) |
| 윤곽 유지 | 약 0.7초 | 2초 유지 + 0.5초 페이드 |
| 상호작용 거리 | 28 px | 20 px |
| 공명 퍼즐 | 45초 지나면 실패 | 실패 없음. 힌트 타이머 → 판정 폭 +8°·감속, 힌트 2번 뒤 Tab 건너뛰기(보상 동일) |
| 복원 반경 기본값 | 72 px | 48 px (큰 소품은 씬에서 키움) |

함께 반영한 GDD 계약 제안: E1·E2(echo 스키마 설명), E4(공명 잔향 색 조각 짝수 검사), G4(꽃 플래그 set_by → 이벤트 id), N1(`shared_echo_found` 계산값), P3(choice id 장소에 밑줄 허용). N2·N3은 ADR-0004에서 이미 해결(재결합 목록 계산값, `can_offer_color()`/`reach_ending()`).

남은 GDD 제안(E3, E5, G1~G3, G5, S1~S3, N4~N5, P2, P4~P5, C1~C3, A1~A5)은 해당 WP에서 처리한다.
