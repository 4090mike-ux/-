## 2. 가장 중요한 원칙: 흑백에서 먼저 읽혀야 한다

이 게임은 대부분의 시간 동안 **흑백**으로 보인다. 색 복원 셰이더는 원색 그림을 명도(Rec.709 휘도)로 바꿔 보여 준다. 그래서:

1. 형태 구분은 **명도 대비**로 한다. 색상 차이만으로 구분되는 그림은 흑백에서 사라진다.
2. 작업 중 Aseprite/Krita에서 **흑백 미리보기 레이어**를 켜 두고 그린다.
3. 잔향 오브젝트는 흑백 상태에서도 주변보다 약간 밝거나 테두리가 또렷해야 한다(감지 전 힌트).

## 3. 감정 색 대역 규칙 (셰이더 계약)

색 복원은 "칠해진 영역(마스크) × 감정 Hue 대역"으로 동작한다. 파랑 잔향을 얻으면 마스크 안의 **파란 픽셀만** 원색으로 돌아온다. 그래서 그림의 색이 대역 규칙을 지켜야 연출이 맞게 나온다.

| 감정 | 색 | 대역 (중심 ± 반폭, 경계 부드러움) | 기호 |
|---|---|---|---|
| 그리움 `longing` | 파랑 | 215° ± 18°, 5° | 물결 |
| 온기 `warmth` | 노랑 | 52° ± 10°, 4° | 해 |
| 꿈 `dream` (임시) | 보라 | 280° ± 15°, 5° | 별 |
| 용기 `courage` (임시) | 주황 | 22° ± 10°, 4° | 불꽃 |
| 치유 `healing` (임시) | 초록 | 125° ± 20°, 5° | 잎 |

수치의 원천은 `game/data/emotions.json`이다. 이 표와 다르면 json이 맞다.

### 규칙

1. **감정 색**: 자기 대역 안, HSV 채도 **0.45 이상**. 팔레트의 `<감정>-dark/mid/light/highlight` 4단계만 쓴다.
2. **중립색**(피부·나무·돌·종이·옷의 무채색): HSV 채도 **0.28 이하**. 셰이더는 채도 0.30 미만 픽셀을 대역 판정에서 뺀다(`band_min_saturation`). 그래서 주황 잔향을 얻어도 피부가 같이 물들지 않는다.
3. **명암 램프의 색상 이동(hue shift)은 대역 반폭 안에서만** 한다. 픽셀아트에서 흔히 쓰는 "그림자는 차갑게, 하이라이트는 따뜻하게" 기법을 크게 쓰면 그림자 픽셀이 다른 감정 대역으로 넘어간다.
4. **빨강(330°~10°)은 예약**이다. 무지개 꽃과 히든 이벤트용. 일반 소품에 진한 빨강을 쓰지 않는다.
5. 청록(150°~195°) 같은 대역 사이 색은 채도 0.28 이하로만 쓴다(어느 잔향으로도 복원되지 않으므로 전역 채도 연출에만 반응한다).

## 4. 색각 이상 대응 (자르면 안 되는 항목)

- 모든 감정 색 표시(잔향 윤곽, 정원 꽃, UI 아이콘, 퍼즐 조각)에 **기호를 함께** 그린다: 파랑 = 물결, 노랑 = 해, 보라 = 별, 주황 = 불꽃, 초록 = 잎.
- 기호 최소 크기 **7×7 px**(480×270 기준). 흑백에서도 기호 모양이 구분돼야 한다.
- 퍼즐은 색 대신 기호만으로도 풀 수 있어야 한다(WP-14 완료 기준).
- 색약 모드(WP-36)는 Hue 대역 재매핑으로 처리한다. 아트를 따로 만들지 않는다.

## 5. 레이어·에셋 규칙

| 규칙 | 이유 |
|---|---|
| 배경은 **원색 한 장**으로 그린다. 흑백판은 셰이더가 만든다 | 작업량을 절반으로 줄인다. 특별 연출용 흑백판만 예외 |
| **잔향 오브젝트는 별도 스프라이트/레이어**로 분리한다 | 마스크에 오브젝트 실루엣을 그려 "그 물건만" 색이 돌아오게 하기 위해 |
| 감정 색은 잔향과 관련된 물건에 집중해서 쓴다 | 흩어져 있으면 잔향 하나에 화면 여기저기가 같이 물든다 |
| 외곽선 1px, 가장 어두운 색은 `neutral-ink` | 흑백에서 실루엣 유지 |
| 파일: `game/art/<bg|char|ui|vfx>/<챕터>/<이름>.png` + 원본 `.aseprite` | Git LFS로 관리(.gitattributes) |

## 6. W-FACE: 스케치 얼굴

- NPC 얼굴은 3단계(canon §2): 0 = 윤곽만, 1 = 흐린 눈·입 선, 2 = 완성.
- 단계별 초상·스프라이트 얼굴을 따로 그리지 말고, **얼굴 디테일을 별도 레이어**로 두어 단계에 따라 켠다.
- 주인공 두 사람은 서로에게 1단계로 시작한다.

## 7. AI 생성물 규칙

- AI 이미지 생성은 **레퍼런스·콘셉트 용도로만** 쓴다. 최종 픽셀은 사람이 그리거나 직접 수정한다.
- 결과물은 팔레트로 양자화한다(`tools/quantize.py`, WP-10에서 작성 예정).
- 출시물에 들어가는 모든 AI 관련 에셋은 [docs/ai_usage.md](../ai_usage.md)에 기록한다(스팀 AI 공개 대상).
